# MR Paints

Five-page React website built with Vinext. Run `npm install`, then `npm run dev`. Production build: `npm run build`.

Contact enquiries open the visitor's email client addressed to info@mrpaints.in. They are not stored or sent by a server.

Product categories are introductory content; confirm the actual catalogue and specifications with MR Paints before public launch.
