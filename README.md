# MR Paints

Five-page React website built with Vinext. Run `npm install`, then `npm run dev`. Production build: `npm run build`.

Contact enquiries open the visitor's email client addressed to info@mrpaints.in. They are not stored or sent by a server.

Product categories are introductory content; confirm the actual catalogue and specifications with MR Paints before public launch.

Interior photograph: Alex Tyson / Unsplash, https://unsplash.com/photos/a-living-room-filled-with-furniture-and-green-walls-cmNSArXSG24 (Unsplash License). Used as colour inspiration, not as a completed MR Paints project.

## Colour refresh
- Home banner carousel: three slides, swipe/keyboard navigation, previous/next, pagination and pause/play. Automatic rotation respects reduced-motion preferences and stops on focus or manual navigation.
- Six interactive inspiration swatches. Display colours are illustrative, not a verified product shade catalogue.
- Original concept packaging: public/images/mr-paint-bucket.png. Generated using built-in imagegen.
- Image prompt: Premium photorealistic white paint bucket, lid and handle, white studio background, violet label with flowing magenta, orange and teal bands; exact text "mrpaints" only.
- Presentation reference: https://www.asianpaints.com/ and https://www.asianpaints.com/products.html . MR Paints artwork and layout are original.
